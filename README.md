## ◈ O QUE É ISTO?

Este repositório contém o meu currículo pessoal — um ficheiro HTML estático, sem frameworks, sem dependências, sem complicações. Puro HTML + CSS + JavaScript vanilla, com bilingual toggle PT/EN integrado e otimizado para impressão.

Porque um CV em PDF é 2015. Um CV em HTML é atitude.

## ◈ COMO USAR

**Ver localmente:**
```bash
# Opção 1 — abre directamente no browser
open nilton.html

# Opção 2 — serve via HTTP (para evitar CORS de fontes)
npx serve .
# ou
python3 -m http.server 8000
```

**Imprimir / exportar PDF:**
```
Ctrl + P  →  Guardar como PDF
```
O layout adapta-se automaticamente para impressão — sem elementos desnecessários, margens correctas, pronto para enviar a recrutadores.

**Trocar idioma:**
```
Clica no botão "EN / PT" (canto superior direito)
ou
Ctrl + L
```
